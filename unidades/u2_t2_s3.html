¿Qué es SQuaRE?

La familia de normas ISO/IEC 25000 es el resultado de la evolución de las normas ISO 9126 e ISO 14598. Su objetivo es proporcionar una guía para el uso de los nuevos estándares de requisitos de calidad del producto software y su evaluación.

Divisiones de la Familia ISO 25000

SQuaRE se organiza en cinco áreas principales:

2500n: Gestión de Calidad
2501n: Modelo de Calidad
2502n: Medición de Calidad
2503n: Requisitos de Calidad
2504n: Evaluación de Calidad

El Modelo de Calidad del Producto (ISO/IEC 25010)

Este estándar define ocho características fundamentales que deben evaluarse en cualquier producto de software:

Adecuación Funcional

Grado en que el software proporciona funciones que satisfacen las necesidades declaradas (Completitud, Corrección, Pertinencia).

Eficiencia de Desempeño

Relación entre el nivel de rendimiento y la cantidad de recursos utilizados (Tiempos de respuesta, recursos, capacidad).

Compatibilidad

Capacidad de dos o más sistemas para intercambiar información o compartir el mismo entorno (Coexistencia, Interoperabilidad).

Usabilidad

Esfuerzo necesario para el uso por parte de los usuarios (Aprendizabilidad, Operabilidad, Accesibilidad).

Fiabilidad

Capacidad del sistema para mantener su nivel de rendimiento bajo condiciones establecidas (Madurez, Disponibilidad, Recuperación).

Seguridad

Protección de información y datos (Confidencialidad, Integridad, No repudio, Responsabilidad).

Mantenibilidad

Facilidad para que el software sea modificado (Modularidad, Reusabilidad, Analizabilidad, Capacidad de prueba).

Portabilidad

Facilidad con que el software puede ser transferido de un entorno a otro (Adaptabilidad, Instalabilidad).

Proceso de Evaluación (ISO/IEC 25040)

Pasos secuenciales para llevar a cabo la evaluación del producto:

1. Establecer requisitos
2. Especificar la evaluación
3. Diseñar la evaluación
4. Ejecutar la evaluación
