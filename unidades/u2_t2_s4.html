Definición del Proceso de Evaluación

Para evaluar la calidad de forma objetiva, es necesario definir escalas de puntuación y aplicar métricas específicas sobre el producto y el proceso de pruebas.

1. Escalas de Medición (Figura 13)

Rango de Medición Puntuación Grado de Satisfacción

Ejemplo de Métrica: Eliminación de Defectos

Esta métrica evalúa la eficacia del equipo para corregir fallos detectados durante las pruebas.

Ficha Técnica de Métrica M2
Nombre
Eliminación de defectos
Tipo
Cuantitativo (Calidad del Producto)
Descripción
¿Cuántos errores detectados han sido corregidos satisfactoriamente?
Fórmula
X = A / B
Donde A = N° defectos corregidos | B = N° defectos detectados
Frecuencia
Semanal (Fase de ejecución de pruebas)

Ejemplo de Métrica: Requerimientos Probados

Utilizando el enfoque GQM (Meta-Pregunta-Métrica), se busca determinar el porcentaje de cobertura de las pruebas.

Ficha Técnica de Métrica M15
Meta (Goal)
Evaluar el proceso de prueba
Pregunta
¿Se requiere saber el número de requerimientos probados?
Métrica
Porcentaje de requerimientos cubiertos con casos de prueba diseñados
Fórmula
X = (A / B) * 100
Donde A = Requerimientos con casos diseñados | B = Total de requerimientos
Valor deseado
100%

Uso de Matrices de Evaluación

Al final, estos valores se vuelcan en una Matriz de Calidad (como se muestra en la Figura 16 del compendio), donde se cruza la característica (ej. Fiabilidad), la subcaracterística (ej. Madurez) y el valor obtenido para determinar si el producto puede ser liberado a producción.
